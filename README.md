# Портфолио + резюме

Готовый адаптивный мультиязычный статический сайт без сборщика и внешних JavaScript-зависимостей.

## Как заполнить

Контактные данные и ссылки находятся в `content.js`. Тексты интерфейса и профильный контент находятся в JSON-файлах:

- `locales/kk.json` — қазақша;
- `locales/ru.json` — русский;
- `locales/en.json` — English.

Пустая ссылка в `content.js` автоматически скрывает соответствующую кнопку или иконку.

Также замените:

- заголовок, description и Open Graph-тексты в `index.html`;
- инициалы в `assets/favicon.svg`;
- текст в `assets/og-cover.svg`;
- при необходимости шрифты и цвета в начале `styles.css`.

## Локальный запуск

Можно открыть `index.html` напрямую или запустить локальный сервер:

```powershell
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Проверка

1. Проверьте меню, переключение темы и языка, все карточки проектов.
2. Проверьте ширины 320, 768, 1024 и 1440 px.
3. Нажмите «Распечатать резюме» и проверьте предпросмотр A4.
4. Убедитесь, что WhatsApp, email и все внешние ссылки открываются корректно.
5. Запустите Lighthouse в production-окружении.

## Деплой

Папку можно разместить как статический сайт на GitHub Pages, Netlify, Cloudflare Pages или Vercel. Команда сборки не нужна; публикуемая директория — корень проекта.
