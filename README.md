# Портфолио + резюме

Готовый адаптивный статический сайт без сборщика и внешних JavaScript-зависимостей.

## Как заполнить

Все персональные данные находятся в одном файле — `content.js`. Там же задаются проекты, опыт, навыки, образование, контакты и ссылка на резюме.

Также замените:

- заголовок, description и Open Graph-тексты в `index.html`;
- инициалы в `assets/favicon.svg`;
- текст в `assets/og-cover.svg`;
- при необходимости шрифты и цвета в начале `styles.css`.

## Локальный запуск

Можно открыть `index.html` напрямую или запустить локальный сервер:

```powershell
python -m http.server 8080
```

После этого откройте `http://localhost:8080`.

## Проверка

1. Проверьте меню, переключение темы и все карточки проектов.
2. Проверьте ширины 320, 768, 1024 и 1440 px.
3. Нажмите «Распечатать резюме» и проверьте предпросмотр A4.
4. Убедитесь, что все внешние ссылки и адрес почты заменены.
5. Запустите Lighthouse в production-окружении.

## Деплой

Папку можно разместить как статический сайт на GitHub Pages, Netlify, Cloudflare Pages или Vercel. Команда сборки не нужна; публикуемая директория — корень проекта.
