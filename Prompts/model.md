## ПРОМПТ

Создай для меня **один цельный сайт-портфолио, объединённый с резюме** (не два разных документа, а единая страница/сайт, где резюме органично встроено в портфолио).

### Обо мне
- Имя: [Имя Фамилия]
- Профессия / специализация: [например: UX/UI-дизайнер, Frontend-разработчик, маркетолог-аналитик]
- Кратко о себе (1–2 предложения, суть и позиционирование): [текст]
- Ключевые навыки: [список 6–10 навыков]
- Опыт работы (компания, должность, период, 2–3 буллита с результатами — для каждого места): [данные]
- Образование / курсы: [данные]
- Проекты для портфолио (название, короткое описание, роль, результат, ссылка/скриншот если есть): [3–6 проектов]
- Контакты: [email, телефон, LinkedIn, telegram, GitHub — что актуально]
- Языки: [если важно для профессии]

### Стиль и настроение
- Стиль: [минимализм / смелый с акцентными цветами / строгий корпоративный / тёплый и личный — выбери один или опиши свой]
- Цветовая палитра: [если есть предпочтения, иначе — "подбери сам под мою сферу"]
- Референсы (если есть сайты/дизайны, которые нравятся): [ссылки или описание]

### Структура сайта
Сделай одностраничный сайт (лендинг) со следующими блоками в этом порядке:
1. **Hero-секция** — имя, профессия, короткий цепляющий питч, кнопка "Связаться" или "Скачать резюме"
2. **Обо мне** — короткий, живой текст без канцелярита
3. **Навыки** — визуально (иконки/теги/прогресс-бары — на твой вкус)
4. **Опыт работы** — таймлайн или карточки, с акцентом на измеримые результаты, а не только обязанности
5. **Портфолио / проекты** — карточки проектов с изображением, описанием, ролью и результатом; кликабельные, если есть ссылки
6. **Образование**
7. **Контакты / призыв к действию** — форма или прямые ссылки на почту/соцсети
8. (опционально) **Отзывы/рекомендации**, если есть

### Технические требования
- Полностью адаптивная вёрстка (мобильные, планшеты, десктоп)
- Быстрая загрузка, чистый семантический HTML
- Плавные, но ненавязчивые анимации при скролле (без перегруза)
- Доступность (контраст текста, читаемые размеры шрифта, alt-теги для изображений)
- SEO-базовые вещи: title, meta description, семантическая разметка
- Сделай тёмную и светлую тему, если это уместно для стиля [или убери этот пункт, если не нужно]

### Тон текста
Пиши тексты для сайта живо и по делу, без штампов вроде "нацелен на результат" и "командный игрок" — покажи конкретику через факты и цифры. Тон: [уверенный / дружелюбный / экспертный — выбери].

### Формат ответа
1. Сначала кратко предложи структуру и стилистическое решение (2–3 абзаца), чтобы я могла подтвердить направление.
2. После моего "ок" — сгенерируй готовый код сайта (HTML/CSS/JS в одном файле или React-компонент — на твой выбор, если не сказано иное).
3. Дай сайт целиком, без сокращений и заглушек типа "здесь будет контент".
