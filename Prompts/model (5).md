# ПРОМПТ ДЛЯ СОЗДАНИЯ САЙТА ПОРТФОЛИО + РЕЗЮМЕ (2 в 1)

> Скопируй этот файл целиком в Lovable / Framer AI / Tilda AI / Wix AI / ChatGPT / Meta AI для генерации сайта.

---

### МАСТЕР-ПРОМПТ

```
Создай одностраничный сайт портфолио-резюме. Это ОДИН сайт, который совмещает функции личного резюме и портфолио.

**ОБО МНЕ:**
Профессия / роль: [например: UX/UI дизайнер / Frontend разработчик / Маркетолог]
Опыт: [сколько лет, где работал]
Моя суперсила / позиционирование: [чем ты отличаешься от других? 1 фраза]
Город: Алматы, работаю удаленно по всему миру
Цель сайта: [получить офферы / найти клиентов на фриланс / приглашения на проекты]

**СТРУКТУРА САЙТА (обязательно именно в таком порядке):**
1.  **Hero-секция:** Имя крупно, должность, короткий слоган в 7 слов [Твой слоган], фото, 2 кнопки: [Скачать CV PDF] и [Связаться]. Фон - минимализм.
2.  **About / Обо мне:** 2-3 абзаца истории, а не список. Что я делаю, для кого и какой результат даю.
3.  **Опыт / Experience:** Таймлайн. Для каждого места: Компания, роль, даты, 3 буллета с достижениями в цифрах, а не обязанностями. Пример: "Увеличила конверсию на 34%".
4.  **Избранные проекты / Selected Works [3-6 проектов]:** Для каждого: Обложка, Название, Задача, Мое решение, Стек / Инструменты, Результат в цифрах, Ссылка на кейс или сайт.
5.  **Навыки / Skills:** Раздели на 3 колонки: Hard Skills / Tools / Soft Skills. Сделай визуально, без скучных полосок-прогресс-баров.
6.  **Услуги / Чем могу помочь (если фриланс):** 3 тарифа / пакета с тем, что входит.
7.  **Отзывы / Testimonials:** 2-3 отзыва с фото, именем и должностью.
8.  **Контакты / Contact:** Форма + Email + Telegram + LinkedIn + Behance/GitHub. Текст: "Отвечаю в течение 2 часов".

**ДИЗАЙН И СТИЛЬ:**
Стиль: Quiet luxury, минимализм, много воздуха, как у сайтов Apple / Linear / Stripe. Никаких ярких градиентов.
Палитра: фон #FAF9F6, текст #111111, акцентный [выбери один: #111111 или глубокий синий #0A192F]. Только 2 шрифта.
Типографика: Заголовки - крупный гротеск (Manrope / Inter), текст - легко читается.
Анимация: Плавное появление секций при скролле, hover-эффекты на проектах. Без летящих элементов.
Вайб: Дорого, чисто, профессионально, вызывает доверие. Как портфолио специалиста уровня Senior из Европы/США.

**ТЕХНИЧЕСКИЕ ТРЕБОВАНИЯ:**
- Адаптив 100%: идеально на мобильном, планшете, десктопе
- Светлая тема по умолчанию
- Скорость: легкая, без тяжелых библиотек
- SEO: прописать Title, Description, Open Graph
- Кнопка "Скачать резюме в PDF"
- Языки: RU / EN переключатель в шапке
- Домен-нейтральный код, готовый для деплоя на Tilda / Framer / Vercel

**ЧТО НЕ ДЕЛАТЬ:**
Не делай шаблонный сайт с иконками из 2010-х, не используй фиолетовые градиенты, не пиши воду "ответственный, коммуникабельный".

Сделай так, чтобы через 5 секунд было понятно, кто я и почему я стою дорого.

**РЕФЕРЕНСЫ (добавь свои):**
[Вставь 2-3 ссылки на сайты, которые тебе нравятся]
```
